# Live editing Implementation Plan

> Inline execution. Steps use checkbox syntax.

**Goal:** Edit parameters, on/off, models and chain order of the edit buffer live, with Revert.
**Spec:** `docs/superpowers/specs/2026-11-18-live-edit-design.md`

## Global constraints

- Only `11 44`, `11 47`, `11 48`, `11 49` may be sent by the edit path.
- Every builder matches the captured command fixture.
- Core stays browser-free and immutable (new objects, no mutation).

## Review focus

- A slider drag must not flood the port; the last value must arrive.
- Revert after a model change must restore the model first, then its params.
- A chain move that would split DRV-AMP-IR-EQ is impossible in the UI and rejected by core.
- Live edit off: no control can send.
- A model change in clone mode switches amp mode before selecting the model.

### Task 1: Command builders and edit guard (core)
- Create `packages/core/src/commands.ts`: `setBlockOn(module, on)`, `setAmpMode(clone)`,
  `selectModel(module, code)`, `setParam(module, alg, value)`, `setChain(order)`, `validateChain(order)`,
  `isAllowedEdit(sysex)`, `encodeValue(spec, input)`.
- Test: `packages/core/test/commands.test.ts` against `test/fixtures/pocketedit-commands.json`
  (all module states, amp modes, effect types except the short-form 201, parameters except module 8 alg 5,
  chain orders); guard accepts the four commands and refuses save, select, globals and queries.

### Task 2: Preset edits and diff (core)
- Create `packages/core/src/edit.ts`: `Edit` union (`param`, `on`, `model`, `chain`),
  `applyEdit(preset, edit): Preset`, `editToCommands(preset, edit): Uint8Array[]`,
  `diffPresets(from, to): Edit[]` (chain first, then models, then on/off, then params).
- Test: apply and diff round-trip on the P08 capture; model edit resets params to catalog defaults;
  revert after a model change lists the model before its params; clone mode emits amp mode first.

### Task 3: Web live edit
- Link `edit(bytes)` path guarded by `isAllowedEdit`; coalescing per parameter at 30 ms.
- Hook: `liveEdit` toggle, `restorePoint`, `modified`, `editParam`, `toggleBlock`, `changeModel`,
  `moveUnit`, `revert`; re-read after model and chain changes.
- UI: sliders, switches, selects, block toggle, model select, chain reorder by drag and by arrow buttons.
- Test: link edit guard and coalescing in `apps/web/test/midi.test.ts`.
- Manual: owner validates on the pedal.
